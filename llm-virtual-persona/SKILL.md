# LLM Virtual Persona Construction Skill

実在の人物の公開情報から、LLMベースの仮想ペルソナを構築し、
行動研究や意思決定シミュレーションに活用するための方法論。

## このスキルを使うタイミング

- 直接アクセスが難しい人物（経営者、政治家、専門家等）の意思決定パターンを研究したい
- 公開テキストから個人の心理プロファイルを構築し、仮想的な実験参加者として活用したい
- LLMペルソナの行動的妥当性を体系的に検証したい

## 前提知識

このスキルは以下の知見に基づいて設計されている：

- LLMは集団レベルの平均的パターンの再現には優れるが、個人差の表現には工夫が必要
- テキストデータだけをLLMに与えても行動的ノイズが増える傾向がある
- **理論的スキャフォールディング**（心理学理論に基づく数値化されたプロファイル）を
  組み合わせることで、行動的忠実度が大幅に向上する
- デモグラフィック情報のみでは表層的な再現にとどまる

---

## 全体フレームワーク：3フェーズ構成

```
Phase 1: ペルソナ構築
  ├── Step 1.1 データ収集（多ソーステキスト）
  ├── Step 1.2 心理的スキャフォールディング（理論的プロファイル生成）
  └── Step 1.3 ペルソナ生成（複数バージョン作成）

Phase 2: 行動バリデーション
  ├── Step 2.1 心理尺度への回答生成
  ├── Step 2.2 入力プロファイルとの整合性検証
  └── Step 2.3 最良バージョンの特定

Phase 3: 人間参加者とのベンチマーク比較
  ├── Step 3.1 フルサンプルでのペルソナ生成
  ├── Step 3.2 既存の人間実験の再現
  ├── Step 3.3 確率的変動の検証（複数回実行）
  └── Step 3.4 統計的ベンチマーク比較
```

## Phase 1: ペルソナ構築

### Step 1.1 データ収集

対象人物について、**3種類以上の異なるソース**からテキストデータを収集する。
ソースの多様性が、文脈依存的な表現のバイアスを軽減する。

**推奨ソースの例：**

| ソース種別 | 特徴 | 収集方法の例 |
|-----------|------|------------|
| スピーチ・講演 | 本人の言葉が直接反映される | YouTube API等で書き起こし取得 |
| ニュース記事 | 第三者視点での発言引用を含む | ニュースAPI、スクレイピング |
| 公式文書 | 組織を代表する立場での表現 | PDF抽出ツール等 |
| SNS投稿 | カジュアルな場面での価値観表出 | 各プラットフォームのAPI |
| インタビュー記事 | 質疑応答形式での深い思考表現 | Web記事の収集 |

**収集時の注意点：**
- 各ソースのドキュメント数を記録しておく（再現性のため）
- テキスト前処理（クリーニング、トークン化、標準化）を統一する
- 対象人物ごとに十分なテキスト量があることを確認する
  （全ソースにデータが存在することを適格基準にする）
- デモグラフィック情報（年齢、性別、学歴、職歴等）も別途収集する

### Step 1.2 心理的スキャフォールディング

収集テキストを**既存の心理学理論に基づいて数値プロファイル化**する。
これがペルソナの行動的忠実度を決定する最重要ステップ。

**使用可能な理論フレームワークの例：**

| フレームワーク | 測定次元 | 向いている用途 |
|--------------|---------|-------------|
| 道徳基盤理論（MFT） | 危害、公正、忠誠、権威、純粋 | 倫理的意思決定の研究 |
| Big Five性格特性 | 開放性、誠実性、外向性、協調性、神経症傾向 | 一般的な行動予測 |
| Schwartz価値理論 | 10の基本的価値 | 動機づけ・価値観の研究 |
| 功利主義/義務論スケール | 結果主義 vs ルール主義 | 道徳的ジレンマの研究 |

**プロファイル生成の手順：**

1. テキスト分析ツール（辞書ベースまたはNLPベース）を選定する
2. 各ソース・各ドキュメントごとにスコアを算出する
3. 個人レベルで記述統計（中央値、最小、最大、四分位、標準偏差）を集約する
4. 各次元のスコアを個人プロファイルとして構造化する

**重要な知見：**
- テキスト分析で得た定量スコアを直接プロンプトに埋め込む方が、
  生テキストを渡すよりも行動的忠実度が高い
- 生テキストはLLMに解釈ノイズを持ち込む傾向がある
- 理論的フレームワークがLLMの推論を適切に制約する役割を果たす

### Step 1.3 ペルソナ生成（複数バージョン比較設計）

**必ず複数の入力構成でペルソナを作成し、比較する。**
これにより、どの情報の組み合わせが最も行動的忠実度が高いかを特定できる。

**推奨バージョン構成（最低4パターン）：**

```
Version A: デモグラフィック情報のみ（ベースライン）
Version B: 生テキストデータのみ
Version C: 理論的プロファイルスコア + デモグラフィック情報
Version D: 理論的プロファイルスコア + 生テキストデータ
```

**プロンプト設計の原則：**

各バージョンのシステムプロンプトには以下を含める：

1. **ペルソナの具現化指示**: 「このペルソナとして回答してください。
   あなた自身の意見は含めず、提供データに基づいてください」
2. **入力データの構造化埋め込み**:
   - 数値スコアは明示的にリスト形式で記述
   - テキストデータはファイルとして添付し検索可能にする
3. **実験の文脈説明**: 使用する尺度・課題の目的を説明
4. **回答形式の明示**: スケール、選択肢、出力フォーマットを指定
5. **根拠の要求**: 各回答に対するrationalを必ず求める（検証用）

**LLMパラメータ設定：**
- temperature: 1.0（人間の回答の自然なばらつきを模倣）
- top_p: 1.0

## Phase 2: 行動バリデーション

### Step 2.1 心理尺度への回答生成

Phase 1で使用した理論フレームワークに対応する**標準化された心理尺度**を
各バージョンのペルソナに回答させる。

例：MFTをスキャフォールディングに使った場合 → MFQ（道徳基盤質問紙）を実施

**実施時のポイント：**
- 各質問に対してスコアだけでなく根拠（rationale）も生成させる
- Part単位（関連度評価、同意度評価等）で分けて実施する
- 回答を集約してファンデーションごとの合計スコアを算出する
- 比較のため、入力スコアと同じスケールに正規化する

### Step 2.2 入力プロファイルとの整合性検証

ペルソナの回答から得たスコアと、Step 1.2で算出した入力プロファイルを比較する。

**算出すべき指標：**

| 指標 | 目的 | 閾値の目安 |
|------|------|-----------|
| Pearson相関 | 入力と出力の線形関係の強さ | r > 0.5 で良好 |
| 平均差（Mean Difference） | 系統的なバイアスの有無 | 小さいほど良い |
| 分散 | 個人間の安定性 | 小さいほど良い |
| Bland-Altman一致限界 | 実用的な一致度の範囲 | 95%の値が範囲内 |

**各次元ごとに、各バージョンの性能を比較し、
最も安定的かつ高い相関を示すバージョンを特定する。**

### Step 2.3 最良バージョンの特定

バージョン間比較の判断基準：

1. **相関の一貫性**: 複数の次元にわたって安定的に高い相関を示すか
2. **バイアスの小ささ**: 系統的な過大/過小評価がないか
3. **理論的整合性**: 次元間の関係パターンが理論と一致するか

**経験則として期待される傾向：**
- 理論的プロファイルスコアを含むバージョンが最も高い忠実度を示す
- 生テキストのみのバージョンは相関が低くなりやすい
- デモグラフィック情報のみでは表層的な類似にとどまる
- テキスト＋理論の組み合わせは理論のみよりやや不安定になる場合がある

## Phase 3: 人間参加者とのベンチマーク比較

### Step 3.1 フルサンプルでのペルソナ生成

Phase 2で特定した最良バージョンを使い、全対象者のペルソナを生成する。

### Step 3.2 既存の人間実験の再現

仮想ペルソナの妥当性を検証するため、
**同じ理論領域で人間参加者を対象に実施された既存研究を再現する。**

**再現対象の選定基準：**
- 使用した理論フレームワークとの関連が明確
- 参加者のサンプルサイズが十分（n > 100が望ましい）
- 刺激材料と手続きが論文中に詳細に記述されている
- 定量的な結果（相関係数、回帰係数等）が報告されている

**プロンプト条件の設計：**

人間が課題に取り組む際の心理過程に対応する**複数のプロンプト条件**を設ける：

```
条件A: 特性分離プロンプティング
  → 各課題に対して、関連する1つの特性スコアのみに基づいて回答させる
  → 人間が特定の道徳次元に焦点を絞って判断する状況を模倣

条件B: 統合特性プロンプティング
  → すべての特性スコアを統合的に使って回答させる
  → 人間の直感的・全体的な道徳判断を模倣
```

**経験則として期待される傾向：**
- 統合特性プロンプティングの方が内的一貫性が高く、
  人間データとの構造的類似度も高い
- 特性分離プロンプティングは理論的シグナルを検出できるが、
  実行間の安定性が低い

### Step 3.3 確率的変動の検証

LLMの出力は確率的であるため、**各条件を最低5回繰り返し実行する。**

**検証すべき項目：**
- 記述統計の安定性（M, SDが実行間で一貫しているか）
- 相関構造の一貫性（変数間の相関パターンが再現されるか）
- 回帰係数の符号安定性（各予測変数の方向が一致するか）
- 回帰係数の大きさの変動幅（SDが許容範囲内か）

**分析手法：**
- 各実行でOLS回帰とRidge回帰（λ=1）の両方を推定する
- 実行間の係数安定性サマリーを作成する
  （平均、SD、最小、最大、正負の符号カウント）
- R²の範囲を確認する
- 5回の実行結果を平均化して最終的な代表値とする

### Step 3.4 統計的ベンチマーク比較

仮想ペルソナの結果を人間データと正式に比較する。

**実施すべき比較分析：**

| 分析手法 | 目的 | 判断基準 |
|---------|------|---------|
| 記述統計の並列比較 | 全体的な分布の類似度 | 平均・SDが近いか |
| Fisher r-to-z変換 | 相関係数の差の検定 | p > .05 なら差がない |
| Chow検定 | 回帰係数の差の検定 | p > .05 なら差がない |
| 効果の方向性比較 | 理論的パターンの再現 | 符号が一致するか |

**解釈のフレームワーク：**

LLMペルソナの結果を解釈する際は以下を考慮する：

1. **構造的整合性**: 変数間の関係パターン（相関構造、回帰の方向性）が
   人間データと一致するかが最も重要
2. **効果量の減衰**: LLMペルソナは一般的に人間より効果量が小さい傾向がある。
   これは必ずしも失敗ではなく、対象集団の特性を反映している可能性がある
   （例：経営者は感情的反応が抑制されたプロフェッショナルな推論を示しやすい）
3. **特定次元の弱さ**: 一部の心理次元（例：権威）で整合性が低くなることがある。
   これは理論的制約が弱い次元や、テキストからの推定精度が低い次元で起こりやすい

## 制限事項と注意点

1. **循環性リスク**: LLMの事前学習データに対象人物の情報が含まれている可能性がある。
   理論的スキャフォールディングにより軽減されるが、完全には排除できない。
2. **感情シミュレーションの限界**: LLMは道徳判断の認知的構造は再現できるが、
   感情的強度は減衰する傾向がある。
3. **代替ではなく補完**: 仮想ペルソナは人間参加者の代替ではなく、
   アクセス困難な集団に対する補完的研究ツールとして位置づける。
4. **理論依存性**: スキャフォールディングに使用する理論フレームワークの選択が
   結果に大きく影響する。研究目的に最も適合するフレームワークを慎重に選定する。

## 発展的応用

- **マルチエージェントシミュレーション**: 複数の仮想リーダーを危機対応・交渉場面に
  配置し、集団意思決定のダイナミクスを研究する
- **自己分析パイプライン**: LLMに自身のテキストコーパスを理論的レンズで分析させ、
  研究者のフレーミングへの依存を低減する
- **アンサンブルエージェント**: 同一ペルソナの複数インスタンスに審議させた後に
  最終回答を生成し、安定性を向上させる
- **複数理論の統合**: MFT + Big Five等、複数フレームワークを組み合わせて
  多次元的なリアリズムを追求する
