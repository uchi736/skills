# LLM ブラインド・ピアレビュー創作フレームワーク

複数のLLMエージェントが互いの初稿にフィードバックを提供しつつ、
改稿は独立して行うことで、外部からの批評の恩恵を受けながら
独自の創作軌道を維持する手法。

## このスキルを使うタイミング

- LLMに創造的な文章（SF小説、短編、物語など）を書かせたいとき
- 単一エージェントの出力が画一的・テンプレート的で不満なとき
- マルチエージェントのディスカッションやディベートで内容が均質化してしまうとき
- より小さいモデルで、大きい単一モデルに匹敵する創作品質を得たいとき
- 複数の視点・文体を活かした多様な創作物を同時に得たいとき

## 前提知識

### なぜ「制約された情報フロー」が創造性を高めるのか

マルチエージェント対話フレームワーク（ディベート、ディスカッション等）は
推論や事実性の改善には有効だが、創作においては逆効果になりうる。
エージェントが互いの進化する出力を繰り返し参照すると、
表現やテーマが収束し、独自性が失われる（均質化効果）。

これはグループブレインストーミング研究の知見と一致する：
対面で対話するグループは、個人が独立して作業するグループより
少なく独創性の低いアイデアを生む傾向がある。

**核心原理：** 創造性は「より多くの対話」ではなく
「適切な情報フロー制約」によって向上する。
批評（何を改善すべきか）は共有するが、
改稿結果（他者がどう改善したか）は見せない。
この非対称性が、外部視点の恩恵と独立した創造的探索を両立させる。

### 教師型・ディベート型との違い

| アプローチ | 情報フロー | 創造性への影響 |
|-----------|----------|-------------|
| 教師型（一対多の指導） | 中央集権的フィードバック | 全員が同じ方向に修正→均質化 |
| ディベート型（相互批評） | 他者の出力に直接露出 | 表現・テーマの収束 |
| ディスカッション型（協調合成） | 反復的な相互参照 | 段階的なアラインメント |
| **ブラインド・ピアレビュー型** | **批評のみ共有、改稿結果は非公開** | **独立した創造的軌道を維持** |

## 全体フレームワーク

```
[プロンプト + ペルソナ割当]
        │
        ▼
┌─── Phase 1: Compose（独立執筆）───┐
│  Agent A → 初稿A                    │
│  Agent B → 初稿B                    │
│  Agent C → 初稿C                    │
└─────────────────────────────────────┘
        │
        ▼
┌─── Phase 2: Review（相互レビュー）──┐
│  Agent A → 初稿B,Cへのフィードバック │
│  Agent B → 初稿A,Cへのフィードバック │
│  Agent C → 初稿A,Bへのフィードバック │
└─────────────────────────────────────┘
        │
        ▼
┌─── Phase 3: Revise（独立改稿）──────┐
│  Agent A: 自分の初稿A + 受け取ったFB │
│  Agent B: 自分の初稿B + 受け取ったFB │
│  Agent C: 自分の初稿C + 受け取ったFB │
│  ★ 他者の改稿結果は見ない            │
└─────────────────────────────────────┘
        │
        ▼ （必要に応じてPhase 2-3を繰り返す）
        │
  [最終出力: 3つの独立した作品]
```

**重要な制約:** Phase 3（改稿）では、エージェントは
(a) 自分の前回の稿、(b) 受け取ったフィードバックのみを参照する。
**他のエージェントの改稿結果は絶対に見せない。**
これがフレームワークの核心であり、均質化を防ぐ鍵。

## 各フェーズの詳細

### Phase 0: ペルソナ割当

**目的：** 多様な視点から創作するために、各エージェントに異なる人格を与える。

**設計指針：**
- N=3 エージェントが最適（後述の根拠参照）
- 各ペルソナは互いに異なる創作哲学・関心軸を持つこと
- ペルソナは全ラウンドを通して固定する（一貫性のため）
- 各ラウンドのプロンプトでペルソナを繰り返し明示する（忘却防止）

**ペルソナ設計例（SF創作の場合）：**

| ペルソナ | 特徴 | 重視する要素 |
|---------|------|-----------|
| 人間性重視の作家 | 人間の感情・関係性にフォーカス | キャラクターの深み、倫理的問い |
| 未来技術志向の作家 | テクノロジーと社会変化にフォーカス | 科学概念の統合、推論の論理性 |
| 生態系志向の作家 | 環境・生態系の視点にフォーカス | 世界構築、象徴と比喩 |

**他ジャンルへの応用時：** ジャンルに合わせてペルソナ軸を再設計する。
重要なのは「互いに異なる創作的関心軸」を持つこと。

### Phase 1: Compose（独立執筆）

**入力：** プロンプト + ペルソナ定義
**出力：** 各エージェントの初稿

**実行手順：**
1. 各エージェントにプロンプトとペルソナを与える
2. 作品のみを出力させる（解説・メタコメントは含めない）
3. 出力フォーマット制約を全エージェント共通にする
   - 目標語数、形式、禁止事項を統一
   - 評価ノイズを最小化するため

**プロンプト設計のポイント：**
- ペルソナの明示：「あなたは[ペルソナ名]として執筆してください」
- 出力形式の指定：「物語本文のみを出力し、コメンタリーは含めないでください」
- 語数の指定：目的に応じて設定（研究では約300語）

### Phase 2: Review（相互レビュー）

**入力：** 他のエージェントの初稿
**出力：** 各初稿へのターゲットフィードバック

**フィードバックの焦点（SF創作の場合）：**
- 独創性：コンセプトはどの程度斬新か
- 世界構築の機会：設定をより深く描写できる箇所
- 推論の一貫性：SF設定内のロジック整合性
- イメージの強化：より鮮明な描写が可能な箇所
- キャラクターの深み：動機・葛藤の掘り下げ

**レビュープロンプトの設計原則：**
- 具体的・建設的な改善提案を求める
- 「ここが悪い」ではなく「こうするとより良くなる」形式
- 創造性と品質の両面を評価対象にする
- 各エージェントが自分以外の全員の初稿をレビューする

### Phase 3: Revise（独立改稿）

**入力：** (a) 自分の前回の稿 + (b) 受け取ったフィードバック
**出力：** 改稿版

**★ 絶対的な制約：他のエージェントの改稿結果は入力に含めない**

**改稿プロンプトの設計原則：**
- 「以下のフィードバックを参考に、あなたの前回の稿を改善してください」
- 受け取った全フィードバックを提示する
- 自分のペルソナを再度明示する
- 出力形式の制約を再度適用する

### ラウンドの反復

Phase 2-3 を複数ラウンド繰り返すことができる。

**経験則：**
- **3ラウンドが最適。** ほとんどの評価次元で3ラウンドでピークに達する
- 4ラウンド以降は品質が低下する傾向がある
- 科学概念の統合と論理性は4ラウンド目まで微増するが、その後低下する

## パラメータ設定ガイド

### エージェント数

| エージェント数 | 推奨度 | 根拠 |
|-------------|-------|------|
| 2 | △ | フィードバックの多様性が不足 |
| **3** | **◎ 推奨** | **品質・効率のバランスが最良** |
| 4 | △ | フィードバック希薄化が始まる |
| 5+ | ✕ | 全指標が一様に低下する |

エージェント追加はラウンド追加と異なり、**全指標を一様に低下させる**。
これはフィードバック希薄化（各エージェントが処理すべき情報量の増大）が
原因と考えられる。

### デコーディングパラメータ

| パラメータ | 推奨値 | 根拠 |
|-----------|-------|------|
| top_p | 0.9 | 創造性と一貫性のバランス点 |
| temperature | 0.9〜1.0 | 中程度が最適 |

**トレードオフの理解：**
- top_p を上げる（→1.0）：科学概念の統合と世界構築が向上するが、論理性と倫理的テーマがやや低下
- temperature を上げる（→1.5）：概念と世界構築が大幅に向上するが、論理性が顕著に低下
- キャラクターの深みは temperature ≈ 1.0 でピークに達し、それ以降は低下

**原則：** 創造性と一貫性のトレードオフが存在する。
用途に応じて調整するが、中程度の設定がデフォルトとして安定。

### 推論コスト

ブラインド・ピアレビュー方式は単一エージェントの約9倍の推論コストがかかる
（3エージェント × 3ラウンド）。ただし：
- より小さいモデルでこのフレームワークを使うことで、
  より大きいモデルの単一エージェント出力を上回ることが可能
- つまり、モデルスケーリングの代替としてインタラクション構造を活用できる
- 例：1Bモデル×ブラインドレビュー ≥ 3Bモデル×単一エージェント（同一ファミリー内）

## 評価フレームワーク（オプション）

生成物の品質を評価したい場合、以下の3層評価を推奨する。

### 層1: LLM-as-a-Judge（品質評価）

別のLLM（できれば生成モデルとは異なるファミリー）に5段階で評価させる。

**SF創作の評価次元例：**
1. 科学概念の統合度
2. 推論の論理的一貫性
3. キャラクターの深み
4. 没入的な世界構築
5. 倫理的・哲学的テーマ

**実施上の注意：**
- 各作品を3回評価し平均を取る（評価の安定性のため）
- 0-5のスケールを使用する（人間との整合性が最も高い傾向がある）
- 生成モデルと評価モデルが同一ファミリーの場合、自己選好バイアスに注意
  → ルールベース指標と併用して補完する

### 層2: ルールベース指標（新規性・多様性評価）

品質とは独立に、生成物の新規性を定量的に測定する。

**推奨指標：**
- **トークンレベル驚き度（Surprisal）：** 生成テキストの本質的な多様性
  - 生成トークンの負の対数確率の平均
  - 高いほど予測困難＝多様な表現
  - 注意：モデル依存のため異なるモデル間の比較には不適
- **語彙的KLダイバージェンス：** 参照コーパスからの語彙的逸脱度
  - 生成テキストと参照コーパスのユニグラム分布間のKLダイバージェンス
  - 加法スムージングでゼロ確率を回避
- **意味的新規性（1 - 最大コサイン類似度）：**
  - 文埋め込みを使って参照コーパスとの最近傍類似度を計算
  - 1から引いた値が新規性スコア
- **埋め込み空間ボリューム拡大量：**
  - 参照コーパスの埋め込み共分散行列に生成物を追加した際の対数行列式の差
  - 大きいほど、参照コーパスがカバーしていない意味空間を探索している

**重要な注意：** ルールベース指標は新規性・多様性を測定するが、
品質（一貫性、可読性）は測定しない。
逸脱が大きいことが必ずしも良い創作を意味するわけではない。
LLM-as-a-Judge と組み合わせて解釈すること。

### 層3: 人間評価（検証用）

LLM-as-a-Judge の妥当性を検証するために人間評価を実施する場合：
- 同じ評価次元・同じスケールを使用する
- 複数の評価者で平均を取る
- 整合性指標：ICC(A,1)、Bland-Altman バイアスと一致限界、Pearsonのr
- 経験則として、ICC 0.58-0.65、Pearson r 0.6-0.69 程度の一致が期待される

## チェックリスト

### 必須事項
- [ ] エージェント数は3
- [ ] 各エージェントに異なるペルソナが割り当てられている
- [ ] ペルソナは全ラウンドで固定・繰り返し明示されている
- [ ] Phase 3（改稿）で他者の改稿結果が入力に含まれていない（★最重要）
- [ ] 出力フォーマット制約が全エージェントで統一されている
- [ ] ラウンド数は3

### 推奨事項
- [ ] top_p = 0.9、temperature = 0.9 をデフォルトとする
- [ ] フィードバックは具体的・建設的な改善提案の形式
- [ ] 評価はLLM-as-a-Judge + ルールベース指標の組み合わせ
- [ ] 評価モデルは生成モデルと異なるファミリーを使用

## 制限事項と注意点

1. **ジャンル依存性：** 本手法はSF短編で検証されており、詩、長編小説、音楽など
   他の創作領域への一般化は追加検証が必要
2. **短文向け：** 約300語の短編で検証。長文への適用ではフィードバックの
   粒度や焦点の設計を再考する必要がある
3. **推論コスト：** 単一エージェントの約9倍。小さいモデルの使用で軽減可能
4. **ルールベース指標の解釈：** 参照コーパスからの逸脱が大きいことは
   ランダムさの増大を反映している可能性もある。品質評価と併用すること
5. **自己選好バイアス：** 生成モデルと同じモデルファミリーで評価すると
   スコアが過大評価される傾向がある

## 発展的応用

- **他の創作ジャンルへの適用：** ペルソナ軸と評価次元をジャンルに合わせて再設計
- **長文への拡張：** 章単位でのレビュー・改稿サイクルの導入
- **非対称ラウンド設計：** 初期ラウンドは高 temperature で探索、後半ラウンドは
  低 temperature で洗練、といった段階的設定
- **フィードバック品質の制御：** レビュアーエージェントに専門的な評価基準を
  持たせることで、批評の質を向上させる
- **ビジネス文書への応用：** 創造性が求められる企画書、広告コピーなどへの転用
  （均質化回避が価値を生む領域）
