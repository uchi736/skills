# チャート・表の詳細規定

`corp_pptx.py` の `chart()` / `table()` は以下を自動適用する。ここに書いてあるのは
「なぜそうなっているか」と「手で上書きしてよい範囲」。

## チャート共通

| 項目 | 規定 | 理由 |
|---|---|---|
| 系列色 | BLUE → CYANSUB → TEAL → STEEL → NAVY → 明青 → PERI → CYAN の順 | 主役が最も濃い青になる |
| タイトル | チャート内タイトルは**持たない** | スライドヘッダがタイトル |
| 凡例 | 2系列以上のとき下部に自動表示 | 単系列の凡例は冗長 |
| グリッド線 | 横のみ、`#E3E7EC` 0.75pt | 目立たせない |
| 値軸 | 軸線なし・ラベル9pt | ミニマル |
| 項目軸 | 軸線 `#A6A6A6` | 基線だけ残す |
| **値軸の最小値** | **bar/stack は 0 固定**(自動) | 0始まりでない棒グラフは差を誇張する(IR禁則) |
| フォント | 游ゴシック 10pt | 全体統一 |
| 単位 | チャートの左上に「(単位:億円)」 | 軸タイトルより読みやすい(IR慣行) |

## 種類の選び方

- **bar(集合縦棒)**: 期間ごとの実数の推移・比較。自社のIR資料の主力。
- **stack(積上げ)**: 全体と内訳を同時に。セグメント別売上など。内訳は4つまで。
- **line(折れ線)**: 率(%)の推移、長期トレンド。実数と率を1枚に混ぜたいときは
  スライドを分けるか、率は points 欄に文字で書く(2軸グラフは作らない — 誤読の元)。

## データラベル

- 単系列 bar: 自動で棒の上に太字ラベル(全数字を見せるのがIR流)。
- stack: 白太字で内側。**セグメントが小さすぎて読めない場合は value_fmt を工夫するか
  ラベルを諦めて表(table)にする**。
- line: ラベルなし(始点・終点の値だけ言いたい場合は points 欄へ)。

## value_fmt の例

| 表示したい形 | value_fmt |
|---|---|
| 1,234 | `#,##0` |
| 1,234.5 | `#,##0.0` |
| 12.3% | `0.0"%"` |
| △123(負を三角) | `#,##0;"△"#,##0` |

## 表(table)

| 項目 | 規定 |
|---|---|
| ヘッダ行 | BLUE 塗り・白太字・中央揃え |
| 1列目 | 淡青塗り・太字(行見出し扱い。`first_col_header=False` で解除) |
| ゼブラ | 偶数行 `#F0F5F8` |
| 数値 | 右寄せ(自動判定)。桁区切り必須(データ側でカンマを入れて渡す) |
| 負値 | `△123` 形式・赤字(自動) |
| 空欄 | `-` を入れる(空セルのまま出さない) |
| 単位 | 表の右上に「(単位:億円)」(`unit=` で自動) |
| フォント | 12pt 基準。行が多く高さが詰まるときは `font_size=10` まで下げてよい |

**表の中で色を増やさない**。強調したい1セルがあるなら、そのセルの値の文字列を太字扱いにする
のではなく、スライドの lead か points でその数値に言及する。

## データの渡し方の注意

- 数値はチャートには**数値型**(int/float)で、表には**表示形の文字列**("1,234")で渡す。
- 前年比の符号: チャートはそのまま、表・KPIは `+150` / `△6` の形にして渡す(色は自動)。
- 見込み・予想値のカテゴリ名は「FY26予」のように**「予」「計画」を明示**する。
