# グラフ・表の規定

`chart()` / `chart_pair()` / `table()` が自動で適用する。ここは「なぜそうなっているか」と
「引数で変えてよい範囲」。見本は 18〜23 番の PNG。

## グラフ共通

| 項目 | 規定 | 理由 |
|---|---|---|
| 配置 | **全幅**。右に「ポイント」欄を置かない | 欄があると図が狭く、結論が二重になる(ユーザー評価) |
| 読み取り | 結論は lead、注目点は `highlight` / `bracket` / `callouts` / `target`。lead の根拠の数字を図上に 1 つ置く | 目が図から離れない |
| 定義行 | `subtitle=` に「何の数字か+集計の単位+期間(年度)」。▍は付かない(▍はリード専用) | 時点の無い数字は読めない |
| 値軸 | 値ラベルが全部ある図(単系列 bar・合計付き stack)では値軸と目盛線を消す(`value_axis="auto"`)。chart_pair と line は出す | 同じ数字を 2 通りで見せない |
| 目盛り | 値軸を出すときは 5〜6 本(間隔は 1・2・2.5・5 の倍数) | 11 本の目盛りは読まれない |
| 目盛線・目盛り | 横の目盛線のみ・淡色 0.75pt。軸の外向きの目盛り(tick)は消す | Excel の初期設定を残さない |
| プロット領域 | manualLayout で固定(左 0.55 / 右 0.12 / 上 0.14 / 下 0.42in) | 注記・目標線・直接ラベルの座標が正確になる |
| 系列色 | bar / line: BLUE → CYANSUB → TEAL → STEEL …。stack: BLUE → 明青 → PERI → GREY(上へ淡く、最後の「その他」は灰) | 主役が濃く、TEAL は増加の意味に取っておく |
| 凡例 | stack は凡例を出さず、系列名を最後の棒の右に直接書く(長すぎると凡例に戻して警告)。bar / line の複数系列は下に凡例 | 図と凡例の往復をなくす |
| 折れ線 | 線 2.5pt+○マーカー 7pt | 月ごとの点の位置が読める |
| 文字 | 游ゴシック 12pt(値軸も 12pt)。単位 11pt を右上 | 図の中でも 12pt 以上 |
| 値軸の最小 | bar / stack は 0 固定(ymin を渡しても無視して警告) | 0 始まりでない棒は差を誇張する |
| 上限 | 軸を出すときは注記の余白を確保したきりの良い数。消すときは値ラベル・注記に要る高さから計算。`ymax` 固定で余白不足なら警告 | 注記が線や棒にかぶらない |
| チャート内タイトル | 持たない(スライドのタイトルと定義行) | 二重にしない |

## 種類の選び方

| 見せたいもの | kind |
|---|---|
| 量の差・期間比較 | `bar` |
| 全体と内訳・構成の推移 | `stack`(内訳 4 つまで。円グラフは使わない) |
| 率(%)の推移・トレンド | `line`(`ymin`/`ymax` を明示。目標は `target`) |
| 増減の要因分解 | `waterfall`(値は `[期首, ±増減..., 期末(None で自動)]`。期首・期末は正の実額) |
| 実数と率を 1 枚で | `chart_pair` で左右に分ける(2 軸グラフは作らない) |

## 図の上の注記

- `highlight=i` — 単系列 bar の主役の棒だけ濃紺、他は淡青(他の種類に渡すと警告)。
- `bracket=(i0, i1, "名前と数字")` — 範囲の括り。bar のときだけ、図の上の専用帯に描く。lead の根拠の数字を書く
  (「本番後は月 +420 件前後(本番前は +85 件)」)。
- `callouts=[(i, "一文")]` — その点の真上に 12pt 青太字。2〜3 個まで。折れ線で目標線にかかるときは点の下に回り、
  棒で目標線にかかるときは白地で線の上に載せる(棒から離さない)。
- `target=(値, "目標 90% 以上")` — 破線。ラベルに向き(以上 / 以下 / 上限)を書く(無いと警告)。
  ラベルはデータと反対側に置き、右に注記があれば左端に回る。
- `forecast_from=i` — カテゴリ i 以降を「計画」として縦の破線で区切り、上の帯に「実績 | 計画」。
  カテゴリ名の「(予)」と注の行は別に残す。
- `chart_pair` の各列は `head="Q: 問い"`(必須)+下線、その下にグラフ。lead で両方の答えを 1 文で言う。

## データラベル

- 単系列 bar: 棒の上に太字(全数字を見せる)。値軸は消える。
- stack: 区間の内側(明るい系列は濃い文字)。各棒の上に合計(`totals=True`)。高さ 0.22in 未満の薄い区間は
  棒の右外に 12pt で書く(最後の棒は系列名と一緒に「照会・その他 410」)。`share_of=i` で区分 i を「3,600(63%)」に。
- line: ラベルなし。始点・終点や注目点は callouts で書く。
- waterfall: 全バーに +35 / △20 形式(増加の文字は INK。TEAL の文字は白地で薄い)。期首・期末=BLUE、
  増加=TEAL、減少=RED。連結線は自動。`callouts` で棒の上に注記できる。

## waterfall の規律

- 要因は影響の大きい順(時系列・工程の順は例外)で 8 本まで(超えると警告)。変化全体の 5% 未満の要因は
  「その他」にまとめ、内訳は付録へ。
- 期末を明示するなら期首+増減の合計と一致させる(合わないと警告)。None で自動計算が安全。
- lead は期首→期末の純増減と主な要因を言う。少ないほど良い指標では、改善の要因に callout で評価を書く
  (「FAQ 化がなければ 170 件」)。

## value_fmt

| 表示 | value_fmt |
|---|---|
| 1,234 | `#,##0` |
| 1,234.5 | `#,##0.0` |
| 12.3% | `0.0"%"` |
| △123 | `#,##0;"△"#,##0` |

## 表(table)

| 項目 | 規定 |
|---|---|
| ヘッダ行 | BLUE 塗り・白太字・中央 |
| 1 列目 | PALE 塗り・太字(行見出し)。`first_col_header=False` で解除 |
| 本文の塗り | `zebra=True`(数値の表): 偶数行 BG。`zebra=False`(論証テーブル): 塗りをやめ、行間に GRID の横罫・最終行は GREY で閉じる。縦線なし |
| 強調行 | `highlight_row=i` で LTBLUE+太字(核心の 1 行・未達の行) |
| 数値の列 | 本文セルの過半が数値なら列ごと右寄せ。桁区切りはデータ側で入れる |
| 負値・未達 | `△` 始まりは赤字(自動) |
| 空欄 | `-` を入れる |
| 単位 | `unit=` で右上に「(単位:○)」(無いときは表が上に詰まる) |
| 文字 | 13〜14pt を基準。12pt 未満は 12pt に上げて警告 |
| 行数・折り返し | 7 行まで(行高 0.34in 未満で警告)。セルは 2 行以内(4 行以上の見込みと高さ超過は警告)。多い一覧は Excel に回し、スライドはサマリ |

- **数値の表**: `["指標", "測り方", "しきい値", "現状", "差"]`。しきい値に向き(以上 / 以下)を書き、
  差は `+2` / `△2` の形で渡す。注で「差の符号の意味と単位」を書く。
- **論証テーブル**: `["課題", "現状", "打ち手", "担当"]`、`zebra=False`。
  課題は足りない状態を言う 12 字以内の短句(「判定モデルの信頼性」→「判定モデルが未校正」)。
  現状は観察した事実と数字だけ(評価語を書かない。2 つの率を並べるなら関係を書く)。
  打ち手は動詞で終え、元の資料に目標があれば到達値を添える(無い数字はこしらえない)。
  担当は右端の列に短い名詞(期日があれば「基盤側・6 月」)。担当が 1 つに決まっている表なら列にせずセルに書く。
  観察した事実がない導入の提案では、中央の列を「ないと起きること」にしてよい。
- lead は表全体の結論を 1 文で。強調行を使うなら、その行が主役である理由を lead で言う。
- 表の中で色を増やさない。強調は highlight_row と lead で。

## データの渡し方

- グラフには数値型(int/float)、表には表示形の文字列("1,234")で渡す。
- 見込み・計画のカテゴリ名には「予」「計画」を付け、stack / bar なら `forecast_from` で区切る。
- 題材の資料に無い数字を置くときは、subtitle か source に「(例)」と書く。
