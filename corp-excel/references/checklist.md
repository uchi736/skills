# 納品前チェックリスト(Excel)

生成後、`export_preview.py` の実画像(Excel実機レンダリング=印刷プレビュー相当)を
**全ページ目視**して確認する。見ずに納品しない。

## ブック構成

- [ ] シート名が意味を持っている(「Sheet1」が残っていない)
- [ ] タブ色: 提出=青 / 明細=鋼青 / 作業・データ=灰
- [ ] 提出シートに生データ・中間計算が混ざっていない
- [ ] 「書式ガイド」など作業用シートを消した(テンプレ由来の場合)
- [ ] プレースホルダ [ ] のテキストが残っていない

## シートごと

- [ ] タイトル(sheet_title)がある
- [ ] 単位表記(unit_note)がある
- [ ] 提出シートのグリッド線が消えている
- [ ] 表のヘッダが青塗り白太字になっている
- [ ] 合計行に total_row 装飾(二重罫線)が付いている
- [ ] チャートが表・タイルと重なっていない ← **頻出。必ず見る**
- [ ] 凡例が軸ラベルと重なっていない
- [ ] 棒グラフのY軸が0始まりになっている(ライブラリが強制するが目視でも確認)
- [ ] 列幅が足りず「####」になっているセルがない
- [ ] フリーズペイン(見出し固定)が長い表に設定されている

## 数値

- [ ] 数値が数値型で入っている(左寄せになっている数値=文字列混入のサイン)
- [ ] 負値が △ 赤で表示されている
- [ ] % は比率(0.056)で入っていて 5.6% と表示されている
- [ ] 桁区切りカンマがある
- [ ] 予想・計画値のラベルに「予」「計画」がある
- [ ] 空セルに `-` が入っている(提出表)

## 印刷(PDFプレビューで確認)

- [ ] A4横・幅1ページに収まっている(表が右に切れていない)
- [ ] © Your Company All Rights Reserved. フッターがある
- [ ] ページ番号(n / N)がある
- [ ] 意図しないページ分割がない(表が中途半端に跨いでいない)

## 最後に

- [ ] openpyxl で再オープンして壊れていないことを確認
