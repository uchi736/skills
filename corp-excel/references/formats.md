# 数値書式リファレンス

`corp_xlsx.py` の定数。**値は必ず数値型で入れ、見た目は書式に任せる**のが大原則。

## 定数一覧

| 定数 | 書式文字列 | 1234 / -56 の表示 | 用途 |
|---|---|---|---|
| `NUM` | `#,##0;[Red]"△"#,##0` | `1,234` / `△56`(赤) | 金額・数量の標準 |
| `NUM1` | `#,##0.0;[Red]"△"#,##0.0` | `1,234.0` / `△56.0`(赤) | 小数1桁が必要なとき |
| `PCT` | `0.0%;[Red]"△"0.0%` | `5.6%` / `△1.2%`(赤) | 比率。**値は 0.056 で入れる** |
| `PCT_PT` | `+0.0"pt";[Red]"△"0.0"pt"` | `+0.5pt` / `△0.5pt`(赤) | 利益率の前年差など |
| `YEN_MM` | `#,##0,,"百万円";[Red]"△"#,##0,,"百万円"` | `123百万円`(円の値を表示だけスケール) | 円単位データの百万円表示 |
| `DATE` | `yyyy/m/d` | `2026/7/3` | 日付 |
| `PLAIN` | `#,##0` | `1,234` / `-56`(黒) | チャート軸など△不要の場面 |

## 使い分けの原則

- **△(三角)は日本の財務慣行**。社外向け・報告向けは NUM 系(△赤)を使う。
  エンジニアリング系の生データシートでは PLAIN でよい。
- 百万円/億円へのスケールは:
  - 元データが「円」→ `YEN_MM`(表示だけ変わる。値はそのまま)
  - 元データが最初から「億円」→ `NUM` を使い、単位は `unit_note()` で明記
- 「,,」1つで千円表示、2つで百万円表示(1000で割るごとにカンマ1つ)。
- 兆・億の混在資料では**単位を列見出しに書く**(「売上収益(億円)」)。

## やってはいけない

| ❌ | ⭕ |
|---|---|
| セルに `"1,234"`(文字列) | `1234`(数値)+ NUM |
| セルに `"5.6%"`(文字列) | `0.056` + PCT |
| セルに `"-120"` や `"▲120"` | `-120` + NUM(△赤は自動) |
| 空セルをそのまま | `"-"` を入れる(提出表の場合) |
| `=TEXT(A1,"#,##0")` で文字列化 | 書式で見た目だけ変える |

## Excel関数との関係

書式は表示だけの問題なので、SUM や VLOOKUP は数値のまま機能する。
文字列で入れた瞬間に全部壊れる — これが「数値は数値型で」の理由。
